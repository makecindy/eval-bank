本版纠正 v2 只考 PR 专项的范围偏差。v1 原六项缺陷重新植入 PR base 题包，再叠加 PR #4919 的真实缺陷。生产仓不改。原 v1/v2 发布与成绩均保留；v2 只作为 PR 专项试验，不能替代累加版成绩。

## 公开材料与难度

答题者只拿 candidate：真实业务源码、宿主适配、常规冒烟与产品说明。TASK 只要求自主检查、证实、最小修复和回归，不说明缺陷数量、位置、PR、根因或评分项。产品文档明确来源隔离、只读预览、完整版本语义、容量、兼容和取消的可观察行为，不规定实现算法。隐藏评分器、参考答案、植入记录、既往模型成果均不交给答题者。难度来自发现、跨模块追踪和时序组合；不能靠隐藏产品取舍造分差。

## 评分：整题 1 分，十个能力各 0.1

B01 端点隔离；B02 共享消费者隔离；B03 失败及取消后的队列恢复；B04 工作目录边界；B05 关闭预览；B06 共享 HTML 不被修改。六项分别独立计分，B03 的两个变体须一起通过。

共有 19 个计分检查（B 类 7，V 类 12），另有 R01/R03 两个诊断回归，不重复加权。新项不再次用端点隔离或共享取消作为保护分，避免同一缺陷重复扣分。禁用共享负控会同时失去旧共享能力与新增重试期间共享行为，这是破坏两个不同产品行为，单缺陷回退则已验证各自只失分一次。
