# 题面与交付规范

candidate 应包含 TASK.md、公开产品约定、环境说明、最小真实源码和原有检查。作者侧单独保存 reference、评分器、权重、变异和校准证据。

推荐短提示：

> 请独立检查这个项目，依据产品约定发现并修复可证实的问题，运行验证，并在 BUGS_FOUND.md 记录问题、证据和结果。先读题目与环境说明；仅修改允许的源码，可新增测试，不修改已有测试、运行环境或题面。仅使用本工作目录材料，不访问其他答案或委派。

具体允许路径由题包给出。无需在提示中加入统一一小时限制、冗余过程要求或隐藏考点提示；执行系统的资源限制另外登记。

交付报告应包含实际改动、修复前证据、修复后检查、未完成及未验证范围。自测通过不是正式分数。报告简短但不能省略完成回馈。

依赖与公开检查应预先可用。题包不要求模型联网安装执行代码以修补缺失运行环境。环境探针如允许改动，必须明确列为例外，不与“禁止修改原有测试”冲突。
