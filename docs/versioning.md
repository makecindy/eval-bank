# 版本与发布

questions/<id>/<revision>/ 保存题目定义及维护材料；suites/ 显式锁题目修订与清单哈希。已冻结版本不可原地改写。公开产品语义、评分器或候选源码变化，应生成新修订并说明影响，旧成绩保留。

分发清单与作者原始清单分开：简化题面等分发变换记录旧、新哈希，不伪装成原始快照。下载须校验大小和 SHA-256；解包与验证完成后才进入作答。

Git 保存可维护源码、规则、评分器和构建说明；大运行时、完整项目快照和分发 ZIP 保留于 Release。不得为清理仓库删除仍被已发布索引引用的资产。

作者材料公开不代表允许答题模型读取。运行时仅交付 candidate，评分在独立可信侧执行。评分会执行候选代码，独立目录不等于操作系统沙箱。

历史原始日志仅在审查脱敏后公开。不得提交客户端数据库、账号配置、凭证、私人任务原文或本机开发快照。
