# 规则演进

此页记录演进，当前规则以本目录其它规范及具体冻结题目为准。

- 早期五题：音频、灵动岛、自动恢复、输入框、手机消息顺序，使用历史等权总分与各题原始指标。
- 自主查错扩展：远程文件、D02 缓存与投影；随后统一每题 1 分，suite 显式锁版本。
- D02 v2.1：澄清卡片就绪状态等产品约定，不把合理理解差异算模型错误。
- 远程文件累加升级：保留原能力，补齐真实 PR 暴露的版本、取消、旧路径与兼容问题。
- 七题质量升级：保留旧考点，增加真实时序组合、逐事件诊断、运行资产与控制样本校准。
- 插件化：题库按需下载、短提示、不向模型告知缺陷数量；正式成绩由独立评分及执行有效性证据决定。

旧材料中的统一一小时上限、六分诊断制或“尚无新版成绩”是当时记录，不是当前执行要求。历史结果不得据此改写。
