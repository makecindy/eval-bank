# 评分规则

- 每题满分 1 分。题目 question.json 冻结能力组、权重和组内 ratio/all 规则；全部组权重之和为 1。
- 按提交源码的实际外部行为得分，不按报告长度、修改行数、自报 bug 数量或自建测试数量得分。
- 多题等权。总分为有效题目贡献之和，满分为试卷题数；百分比仅在题目覆盖与版本一致时比较。缺题、未结束、用户中止、环境无效不填零，不伪造完整总分。
- 能力组可有必要前置条件或保护项，但必须在冻结评分规范中明确；不得事后加入扣分规则。
- 同模型不同 harness、provider route、思考强度分别记录。重复复评同一提交不是新独立作答；总榜需明确最近一次或其他聚合口径。
- 保留原始评分与后续有效性更正。环境错误、审批误拒绝、缺依赖等不能直接解释为模型能力不足；模型自身造成的行为失败则由冻结规则裁决。
- 评分器不采用被测模型新增的测试作为判据，并检查题面、环境和原有测试是否被改写。
- 费用统一 USD；有凭据才记录实际花费。公开单价推算必须标注价格日期、来源和 token 分类，不能当实际账单；未知保持 null。

旧原始诊断分数及旧五题百分制属于历史版本，不与当前单题 1 分直接相加。跨版本成绩须分开显示。
