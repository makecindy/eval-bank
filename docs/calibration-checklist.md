# 冻结前检查清单

## 题意与来源

- [ ] 真实源码来源、版本、许可及修改记录可追溯。
- [ ] 公开产品约定足以推出参考实现的关键取舍。
- [ ] TASK 不泄露缺陷数量、位置或隐藏用例。
- [ ] 候选材料不含参考答案、评分器、私人记录或凭证。
- [ ] 新旧能力对照完整，未把旧考点偷偷删除或降为不计分。

## 可运行与评分

- [ ] 干净目录可执行公开检查和可信评分器。
- [ ] 评分实际加载提交代码，而非固定旧输出。
- [ ] 故障基线暴露问题；不强求基线必须零分。
- [ ] 完整参考得到 1 分，刻意漏修版不得满分。
- [ ] 关键修复逐项变异能使对应验收失败。
- [ ] 保护相邻正常行为，阻止禁用缓存、无限缓存、截断内容等绕过。
- [ ] 并发场景使用确定性屏障或虚拟时钟，避免靠脆弱 sleep 排名。
- [ ] 挂起用例有有界清理；环境故障单列而非默认为零。
- [ ] 实际运行日志、环境版本、清单与 SHA-256 留存。

## 冻结与试跑

- [ ] 题目、评分规则和 suite 明确锁定版本。
- [ ] 少量配置试跑后复核分差来源与歧义。
- [ ] 新真实缺陷单独审查，不追改当前分母。
- [ ] 不把逻辑/模拟测试宣称为生产设备或真实性能验收。
